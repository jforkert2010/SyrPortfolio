Pokedex SQL Database Project

Designing and implementing a relational database for Pokémon data using SQL database principles.

SQL Database Design ER Modeling Normalization Data Analysis

Project Overview

This project focused on designing a normalized relational database to manage Pokémon information including species, types, abilities, evolutions, trainers, and battle statistics. The database was structured to reduce redundancy, maintain data integrity, and support efficient SQL querying.

Business Problem

Large datasets with interconnected information require proper database design to maintain consistency and support efficient retrieval of information. The objective was to create a scalable relational database capable of supporting complex relationships and analytical queries.

Skills Demonstrated

  • Relational Database Design
  • Normalization (1NF, 2NF, 3NF)
  • Primary and Foreign Key Relationships
  • SQL Query Development
  • Entity Relationship Modeling
  • Data Integrity Management
