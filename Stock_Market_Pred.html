Big Data Analytics Project – Stock Performance Prediction (IST 718)

This project focused on building a scalable big data solution to predict stock performance using distributed computing and machine learning techniques. Leveraging Python and Apache Spark, I developed data pipelines to ingest, clean, and transform large financial datasets.

The workflow followed the full data science lifecycle, including data preprocessing, feature engineering, model development, and evaluation. A predictive model was implemented to classify or estimate stock success, enabling insight generation for potential investment strategies.

Spark pipelines were used to streamline data processing and model execution, ensuring scalability and efficiency. Additionally, data visualizations were created to identify trends and effectively communicate findings to both technical and non-technical audiences.

Key Outcomes:

  • Built scalable Spark pipelines for large-scale data processing
  • Applied machine learning models to financial data
  • Generated actionable insights for investment decision-making
  • Communicated results through visualization and structured reporting
  • Evaluated ethical considerations, including bias and real-world impact of financial predictions
