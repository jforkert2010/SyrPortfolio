Big Data Analytics – Stock Performance Prediction

IST 718 • Big Data Analytics Project

This project focused on building a scalable big data solution to predict stock performance using distributed computing and machine learning techniques. Leveraging Python and Apache Spark, I developed data pipelines to ingest, clean, and transform large financial datasets.

The workflow followed the full data science lifecycle, including preprocessing, feature engineering, model development, and evaluation. A predictive model was implemented to generate insights for potential investment strategies.

Spark pipelines streamlined data processing and model execution, while visualizations were used to communicate findings effectively to both technical and non-technical audiences.

Key Outcomes

  • Built scalable Spark pipelines for large-scale data processing
  • Applied machine learning models to financial data
  • Generated actionable insights for investment decision-making
  • Communicated results through visualization and reporting
  • Evaluated ethical considerations in financial prediction models
