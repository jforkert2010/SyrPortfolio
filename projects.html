Wine Quality

This project is based on a dataset on a quality assessment of Portuguese Wine. Each wine was tasted by an expert and given a rating from 1 to 10. This data also contained measured values for each wine such as pH. Our goal was to see which of these attributes would predict if the wine was good (rating of 7 or higher). The dataset is from Kaggle.
